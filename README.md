# Академгородок: белки захватили науку

Пошаговая игра для четырёх игроков на одном компьютере. Кланы получают
случайные события, выбирают действия и соперников, накапливают престиж.

## Запуск

Нужен Python 3.10 или новее. Откройте терминал в папке проекта, где
находятся `main.py` и `requirements.txt`, затем выполните:

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

В PyCharm можно открыть проект и запустить `main.py` кнопкой Run после
установки зависимостей в выбранный интерпретатор.

## Как играть

Четыре клана ходят по очереди. В начале хода нажмите «Начать ход»: игра
применит случайное событие к текущему клану. Затем перейдите к действиям,
выберите одно из пяти действий и другого действующего игрока, подтвердите
выбор и передайте ход. Доступность действий зависит от ресурсов.

Клан выбывает при панике от 10 или отсутствии белок. Побеждает действующий
клан с престижем от 30 либо последний оставшийся клан. После завершения
партии можно начать новую игру.

## Файлы проекта

- `main.py` — запускает окно и передаёт нажатия контроллеру.
- `config.py` — правила, данные событий и настройки экрана.
- `game/` — состояние партии, события, действия, контроллер и интерфейс.
- `assets/` — изображения игры.
- `docs/` — правила и проектная документация.
- `tests/` — автоматические проверки игровой логики.

Для запуска игры достаточно зависимости `pygame`, указанной в
`requirements.txt`. Чтобы отдельно запустить тесты, установите `pytest`
и выполните `python3 -m pytest -q` из папки проекта.
