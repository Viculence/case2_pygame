# Интерфейс игры (роль 2 — дизайнер)

## Макет
- `assets/background.jpg` — фон с ночным лесом и зданиями
- `assets/squirrel_fire.jpg` — картинка белки с огнём

## Структура экрана

### Верхняя часть — 4 панели кланов
- 4 карточки в 2 ряда (2 сверху, 2 снизу)
- У каждого клана свой цвет рамки
- Цвета кланов:
  - Клан 1 (Ядерный орех): оранжевый (241, 153, 67)
  - Клан 2 (Институт прикладного дупла): синий (100, 166, 238)
  - Клан 3 (Кедровый консорциум): зелёный (115, 205, 147)
  - Клан 4 (Лаборатория спорных запасов): фиолетовый (192, 143, 227)
- Внутри каждой карточки: 6 иконок ресурсов в ряд, цифры, подписи
- Цифры и подписи окрашены в цвет клана
- Текущий игрок выделяется более толстой рамкой

### Центральная часть — событие
- Карточка события с цветной рамкой:
  - Жёлтая (ACCENT) — для положительных событий
  - Красная (220, 100, 100) — для отрицательных
- Слева — картинка белки с огнём
- Справа — название события и эффект

### Нижняя часть — слева кнопки
- Для стадии `action`: 5 кнопок действий (Торговля, Подкуп, Набег, Союз, Пропаганда)
- Для стадии `target`: 3 кнопки целей + «Назад» + «Подтвердить»
- Кнопки активные — зелёные (86, 130, 103)
- Кнопки неактивные — серые (68, 75, 73)

### Нижняя часть — справа журнал
- Заголовок «ЖУРНАЛ (последние пять записей)»
- Перед каждой записью — цветной маркер того клана, к которому относится событие

## Стадии экрана и кнопки

| Стадия | Что показывается | Кнопка | Команда |
|--------|------------------|--------|---------|
| start | Начало хода | «Начать ход» | start |
| event | Карточка события | «К действиям» | continue |
| action | Меню 5 действий | Выбор действия | action:A1 … action:A5 |
| target | Выбор цели | «Назад», «Подтвердить» | back, confirm |
| result | Итог хода | «Передать ход» | next |
| game_over | Результат партии | «Новая игра» | restart |
| skip | Пропуск действия | «Пропустить действие» | skip |

## UX-правила
1. Себя и выбывшие кланы выбирать нельзя.
2. Если не хватает ресурсов — кнопка серая и неактивная.
3. Причина запрета показывается через `action_reason()` или `target_reason()`.
4. Подтверждение применяет действие один раз.
5. Все изменения ресурсов попадают в журнал.
6. Важные сообщения — в карточке события.
7. Если нет доступных действий — кнопка «Пропустить действие» (skip).

## Что показывать на экране
- Названия кланов — полностью, читаемо.
- Последние 5 записей журнала — с цветными маркерами.
- Коды событий (E1–E16) — НЕ показывать.
- Картинка белки — слева от карточки события.
